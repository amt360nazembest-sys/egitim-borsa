# EğitimBorsa

Sanal parayla (200 USDT), **gerçek Binance canlı verisiyle** kripto ve hisse alım-satımını öğrenmek için eğitim uygulaması.

🔗 **Uygulama:** https://amt360nazembest-sys.github.io/egitim-borsa/

- Spot ve Vadeli (Long/Short, kaldıraç, likidasyon, fonlama)
- NVIDIA, Tesla, AMD gibi hisse kontratları
- MA/RSI göstergeleri, çizim araçları, risk hesaplayıcı, fiyat alarmı
- Kullanıcı adı/şifre ile hesap; veriler cihazında saklanır

> Gerçek para kullanılmaz. Eğitim amaçlıdır, yatırım tavsiyesi değildir.
